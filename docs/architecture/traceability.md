# Traceability Matrix

| Area | Demo requirement | Proof point |
| --- | --- | --- |
| Homepage | Easy sample entry | `/demo` redirect and homepage shortcut |
| Review shell | Clear demo labeling | demo banner in the PR review route |

| Operations | Noise control | scheduled PR reset workflow |

## Notes

The sample repository should feel like a real product workspace, not a test harness. That means the content should read like product planning material and still exercise the exact UI states Commentary cares about.
